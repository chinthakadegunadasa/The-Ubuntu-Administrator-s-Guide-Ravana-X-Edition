## 23.1 The Architecture of Scale
## 23.1 පරිමාණයේ සැලසුම් ශිල්පය

Standard PostgreSQL is a single-node system. For the **Ravana-X** project, which monitors thousands of metrics per second, we require horizontal scaling. **Citus** transforms PostgreSQL into a distributed engine.

මූලික PostgreSQL පද්ධතියක් ක්‍රියාත්මක වන්නේ තනි ඒකකයක් ලෙසය. එහෙත් තත්පරයකට දත්ත දහස් ගණනක් ලැබෙන **Ravana-X** ව්‍යාපෘතිය සඳහා අපට දත්ත සමුදාය තිරස් අතට ව්‍යාප්ත කිරීමට (Horizontal scaling) අවශ්‍ය වේ. **Citus** මගින් PostgreSQL විමධ්‍යගත එන්ජිමක් බවට පත් කරයි.

## 23.2 Deployment with Pigisty
## 23.2 Pigisty මගින් යෙදවීම

Pigisty is the "industrial-grade" distribution for PostgreSQL on Ubuntu. It automates high availability (Patroni) and monitoring (Grafana).

Pigisty යනු Ubuntu මත PostgreSQL ස්ථාපනය කිරීමට ඇති වඩාත්ම වෘත්තීයමය (Industrial-grade) ක්‍රමයයි. එමගින් Patroni සහ Grafana වැනි පද්ධති ස්වයංක්‍රීයව ස්ථාපනය වේ.

> **Architect's Note:** Use the `sharding` strategy for time-series energy data to ensure maximum query performance across 10-node clusters.
